What differs between the four cases?

  • Pyramidal: four nonnegative edge coefficients, using the shared direct pyramidal inequalities and MuJoCo's matching pyramidal contact law.
  • Elliptic norm: hypot(t₁/μ₁,t₂/μ₂) − n ≤ 0, plus a normal nonnegativity row. The norm is nonsmooth at zero tangential force.
  • Signed-square: t₁² + (μ₁/μ₂)² t₂² − μ₁² n|n| ≤ 0. It has the same elliptic feasible set and excludes negative normals; its gradient vanishes at the zero-force apex.
  • Penalty factor: the actual ContactDynamicsFrictionConeFactor on the body pose and contact wrench, with the known pose fixed through ConstVarGraph. It adds 0.5 [max(0, |t|² − μ²n²) / 0.001]² to the physical objective. A separate normal inequality excludes pulling. No hard tangential-cone inequality is added.

The penalty case changes the optimization problem. Finite penalty weight can admit friction violations even when its own optimizer converges. Sigma 0.001 matches the standard dynamics setting; these measurements do not select an optimal penalty weight. The runner checks isotropic friction and vertical contact normals for this factor. Elliptic variants share identical physical inputs, objective before the penalty, and initial forces. Pyramidal forces start at zero; elliptic forces start at 1 N normal force.
