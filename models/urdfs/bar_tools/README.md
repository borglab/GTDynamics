# CMRG timber tools

Tool meshes mounted on `robotN_tool0` of `bar_lab.urdf`: `TimberGripper.stl` (arm 1) and `TimberNailer.stl` (arm 2).

Source: BAR-robot-cell, `setup/tool_meshes/` on `origin/main`. These are the original (not `_NEW`) meshes, which the paper's measured tool constants (grip plane, nailer tip, fitted collision spheres) refer to. Units are metres in the tool0 frame.
