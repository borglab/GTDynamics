THE GTDYNAMICS PROJECT

Robotics, connected
by factor graphs.

One language for robot motion. Express kinematics and dynamics as a graph, then let optimization connect the pieces.

Built on GTSAM, GTDynamics brings together robot models, physical constraints, and trajectory optimization in a C++ library with Python bindings.
